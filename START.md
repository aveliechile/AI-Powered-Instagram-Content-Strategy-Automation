# Instagram en 6 pasos

Todo se hace pegando el prompt correspondiente a Claude Code. Sin instalar nada.

1. **Datos de la marca** → completa `BRAND.md`
2. **Estrategia** → usa `prompts/1-estrategia.md`
3. **Posts** → usa `prompts/2-posts.md`
4. **Captions** → usa `prompts/3-captions.md`
5. **Hashtags** → usa `prompts/4-hashtags.md`
6. **Calendario** → usa `prompts/5-calendario.md`

Cada prompt usa los resultados del paso anterior. Hacelos en orden.
